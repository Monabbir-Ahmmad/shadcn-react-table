# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests, discussions and reviews. Harassment, insults and personal attacks are not tolerated.

To report unacceptable behavior, contact the maintainer privately through [their GitHub profile](https://github.com/Monabbir-Ahmmad). Reports are kept confidential. The maintainer may remove, edit or reject contributions, or block participants who break this code.
