# Support

- **How do I…?** Start with the [docs](https://monabbir-ahmmad.github.io/shadcn-react-table/docs): every feature has a guide with a live example, and the API reference lists every option. Coding agents can read [llms.txt](https://monabbir-ahmmad.github.io/shadcn-react-table/llms.txt).
- **Coming from Material React Table?** See the [migration guide](https://monabbir-ahmmad.github.io/shadcn-react-table/docs/guides/migrating-from-mrt).
- **Still stuck?** Open a [blank issue](https://github.com/Monabbir-Ahmmad/shadcn-react-table/issues/new) with your question.
- **Found a bug?** Open an [issue](https://github.com/Monabbir-Ahmmad/shadcn-react-table/issues/new/choose) with the block version and a small reproduction.
- **Security issue?** Report it privately: see [SECURITY.md](SECURITY.md).

The block is copied into your project by `shadcn add`, so once installed the code is yours. Say in your report if you've changed the installed files.
